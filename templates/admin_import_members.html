How It Works
Toast CSV Format

Your CSV file should have exactly these 4 columns:

  • Name - Member/customer name (required)
  • Customer Number - Toast customer ID (optional)
  • Last Transaction Date - Date of last visit (optional)
  • Outstanding Balance - Amount owed (format: $X,XXX.XX)
What Happens During Import
  1. New members are created with their name and outstanding balance
  2. A default password is generated - they must change it on first login
  3. Existing members are updated with their balance data
  4. Each member gets a unique email based on their customer number or name
  5. All members are set to active status
After Import
  • Members can log in to view their profile
  • Their balance shows in the "Balance" tab on their profile page
  • Admins can view all member balances on the Sales Dashboard
  • All data is read-only (no changes are sent back to Toast)
Tip: After import, go to the Sales Dashboard to see all member balances loaded.
Sample CSV Format

Your Toast Export Should Look Like This:

Name,Customer Number,Last Transaction Date,Outstanding Balance
JW Danforth,C2001,2026-05-19 03:24,"$35,559.36"
Events Draft Room,,2022-06-08 17:23,"$23,959.94"
Phil Rapini,s310,2026-05-19 03:20,"$15,669.96"
SABRES PSE,C2119,2026-03-28 00:41,"$14,035.47"
Adam Martin,C9002,2026-05-20 15:19,"$5,322.97"

Note: The quotes around dollar amounts are fine - the importer handles them.

Troubleshooting
Common Issues:
  • File not accepted: Make sure it's a .csv file (not Excel)
  • Import fails: Check that your CSV has exactly 4 columns with the right headers
  • Missing columns: Toast exports might have extra columns - that's OK, we only use the 4 above
  • Balance issues: Make sure balance format is like "$1,234.56" (dollar sign, commas, 2 decimals)
Import Information
File Requirements
  • Format: CSV (.csv)
  • Columns: 4 (as shown above)
  • Encoding: UTF-8
  • Headers: Name, Customer Number, Last Transaction Date, Outstanding Balance
What Gets Created

Each member gets:

  • Name (from CSV)
  • Email (auto-generated from customer number or name)
  • Outstanding Balance (from CSV)
  • Default password (must change on first login)
  • Active status
View Member Data

After import, visit:

  • Sales Dashboard - See all balances
  • Manage Members - View/edit members
Safe: No data is sent back to Toast. All imports are read-only.
