How It Works
Expected CSV Columns
  • Name — Full name. First word → first name; the rest → last name. (required)
  • Customer Number — Member ID (e.g. C2001, s310). Used to detect duplicates.
  • Account Number — Ignored.
  • Email — Used as login email and duplicate key.
  • Phone — Stored on the member profile.
  • Outstanding Balance — Dollar amount (e.g. $35,812.72 or -$74.59).
What Happens During Import
  1. Members matched by email or Customer Number are updated — name, phone, member number.
  2. Unrecognised rows create new member accounts with a random temporary password.
  3. Username is set to firstlast (lowercase, no spaces, numbers disambiguate duplicates).
  4. Any non-zero Outstanding Balance creates an Order with a single line item:
    "Outstanding balance as of [date]" — $0 tax, $0 gratuity — so you can generate invoices later.
  5. Re-importing the same file is safe: the outstanding-balance order is updated in place.
Tip: After import, visit Manage Members to see all imported accounts.

Quoted dollar amounts and negative balances (credits) are handled automatically.

Troubleshooting
Common Issues:
  • File not accepted: Save as .csv from Excel first (File → Save As → CSV UTF-8)
  • Wrong column headers: Headers must be exactly Name, Customer Number, Account Number, Email, Phone, Outstanding Balance
  • Duplicate members: Matched by email first, then Customer Number — safe to re-import
  • $0 balance rows: Member is created/updated but no order is generated (nothing to invoice)
Import Information
File Requirements
  • Format: CSV (.csv)
  • Columns: 4 (as shown above)
  • Encoding: UTF-8
  • Headers: Name, Customer Number, Last Transaction Date, Outstanding Balance
What Gets Created

Each member gets:

  • Name (from CSV)
  • Email (auto-generated from customer number or name)
  • Outstanding Balance (from CSV)
  • Default password (must change on first login)
  • Active status
